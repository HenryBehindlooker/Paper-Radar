# Datenquellen

Dieses Dokument hält für jede Quelle die **live geprüften** Endpunkte, Limits,
Nutzungsbedingungen und Attributionspflichten fest. Es wird in Phase 1 befüllt;
Angaben stammen ausschließlich aus der offiziellen Doku und aus echten
Antworten (gespeichert unter `tests/fixtures/`), nicht aus dem Gedächtnis.
